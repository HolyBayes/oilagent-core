# Бесплатный web-поиск

DDGS 9.16.1 обращается к DuckDuckGo без регистрации и API-ключа. Поиск не использует LLM. Это не официальный API DuckDuckGo с гарантией доступности: возможны rate limit, таймаут и пустая выдача. Платного fallback нет. `WEB_ENABLED=false` отключает обращения.

Из core/:

```bash
python scripts/search_web.py 'OPEC oil'
python scripts/search_web.py 'EIA oil outlook' --historical
```

По умолчанию вызывается `news` за неделю; historical использует `text`. Выбран только backend `duckduckgo`, без автоматического перебора сервисов. Один вызов adapter запрашивает до 20 результатов, принимает до пяти; timeout клиента 10 секунд, повторов приложения нет. Это timeout HTTP-клиента, не гарантированный общий deadline: библиотека может сделать несколько HTTP-операций на поиск.

## Политика источников в evolution

Рабочий список: **`evolution/policies/web_sources.json`**. Категории `official` и `news` задают разрешённые домены и порядок приоритета. В core находятся схема, загрузчик и проверки, а также `src/analyst/seeds/web_sources.json` для начального запуска. Seed — шаблон, не вторая активная политика.

Загрузчик разрешает main в конкретный SHA и читает файл из этого commit. Рабочие правки, checkout другой ветки и candidate branches не активируют политику. В provenance каждого результата есть `policy_revision`. Путь использует общий `EVOLUTION_REPO_PATH`, включая приоритет system env и разрешение относительного пути от core.

Пустой evolution получает policy при штатном bootstrap/Evolution MCP. Сам поиск ничего не записывает в Git; до bootstrap использует seed с предупреждением `web_policy_seed_fallback` и revision `seed:<hash>`. Старый main без нового файла получает такой же явный fallback. Повреждённая committed policy блокирует поиск; ошибки чтения существующего файла не подменяются seed. Администратор может вручную закоммитить политику в main. Автоматического promotion/release нет; Evolution MCP пока принимает только retrieval-policy.

## Отбор и ответы

HTTPS, hostname с точной границей поддомена, отсутствие userinfo и нестандартного порта проверяются локально. Поле издателя от поисковика не используется для доверия. Проверенный hostname не доказывает конкретный факт. Ссылки самостоятельно не обходятся; произвольные fetch URL отсутствуют.

`published_at` берётся из метаданных поисковика с `date_origin=search_provider`, `retrieved_at` записывается отдельно в UTC. Для свежего запроса исключаются недатированные, будущие и старше семи суток материалы; «сегодня/today» дополнительно требует текущую дату **UTC**. Это не независимая проверка даты оригинального сайта. Для historical дата может отсутствовать, что явно показывается в ссылке; числовые claims тогда запрещены.

Web evidence — поисковая выдержка до 1200 символов с URL, датами, издателем и hash. `numeric_verified` для web означает допуск к проверке чисел из датированной выдержки, а не ручную проверку чисел или доказанную истинность. Валидатор проверяет точное вхождение цитаты и чисел. Смысл, единицы и период по-прежнему требуют оценки; полный текст оригинальной статьи не загружается. Фрагменты передаются как недоверенные данные.

Граф предпочитает PDF для исторического вопроса. Если фрагментов нет либо синтез отказался от ответа, выполняет одну web-попытку. Для явного запроса свежести web обязателен даже при ошибочной классификации LLM; исторический PDF не служит доказательством текущей ситуации. После web второго цикла нет. Обычный RAG-ответ требует routing+synthesis; fallback добавляет не более одного synthesis. Usage первого вызова сохраняется отдельно от `web_synthesis`.

`search_web_sources` доступен через Analyst MCP. `health.web` отражает включённость возможности, не успешность сетевой проверки. Ошибка поиска возвращается явным warning с типом исключения, без provider exception text. При отсутствии свежих evidence ответ имеет `needs_web`. При запросе текущей цены возможен только `partial` с явным сообщением, что текущая котировка не подтверждена. Числовые web-claims со словами «сейчас/сегодня/current/live» отклоняются. Live feed с instrument/price type/timestamp/unit пока отсутствует.

## Проверки

Offline-тесты покрывают поддельные домены, даты, дедупликацию, порядок источников, committed main и seed, игнорирование рабочих/candidate правок, invalid-policy reject, отсутствие рекурсии, приоритет RAG и сохранение usage. Запросы к поисковику в pytest подменены.

Живой backend вернул новости без ключа; локальный фильтр оставил один допустимый источник. Проверка adapter также фиксирует временную ошибку DuckDuckGo; replay настоящей ранее полученной выдачи проверяет фильтрацию отдельно от сети. Это разные свидетельства, их нельзя выдавать за стабильный end-to-end сервис. Результаты: [web-evidence.json](web-evidence.json). Платные модели на этом этапе не вызывались.

Интерфейс и ограничения библиотеки: [DDGS](https://github.com/deedy5/ddgs). Core не использует Tavily и не требует его ключа.


## Актуальный путь 2 ноября 2026

Для явно запрошенного EIA используются официальный RSS и структурированный publisher scope; общий поиск остаётся DDGS с RSS fallback. Topic score не считает название издателя и служебные слова доказательством релевантности. `now_utc` передаётся синтезу явно. Report и web в hybrid обрабатываются независимо; typed publisher aliases EIA/eia.gov нормализуются. При model outage или abstain возможна помеченная excerpt/partial, а не неподтверждённая интерпретация. Реальные web/hybrid ответы — в examples/demo_dialogues.md; качество relevance не гарантируется только доверенным доменом.
