# Контекст страницы и оценка retrieval

Проверено 1 ноября 2026, без вызовов LLM. Исходный corpus/embedding index не менялся.

## Изменение

Векторный поиск выбирал заключительный фрагмент PDF-страницы 7 OPEC о 2026 годе, теряя вводный абзац о 2025. Теперь каждый найденный фрагмент с ненулевым offset может получить `page_intro`: до 800 символов из первого chunk **того же документа и страницы**. Это правило применяется ко всему корпусу, без специальных номеров страниц, издателей или значений показателей. `intro_chunk_id` сохраняет provenance. Индекс пересчитывать не требуется.

`text` и `page_intro` остаются отдельными непрерывными фрагментами. Валидатор допускает цитату из одного поля и отвергает склейку через их границу; разрешение числовых claims остаётся общим для проверенной страницы. Упаковка контекста учитывает оба поля и используется также evaluator. Отбор не доказывает смысловую корректность ответа.

## Протокол

Девять отложенных вопросов с проверенными по исходным PDF опорными цитатами закреплены коммитом `c1117e9` **до изменения поиска**. Они касаются других фактов и периодов того же корпуса. До исправления сохранён исходный прогон; `--baseline` воспроизвёл его полностью. Реализация проверена на development, затем один раз на отложенном наборе, без последующей настройки по его результатам.

Это небольшой открытый набор вопросов из тех же двух документов. Он не является скрытым benchmark, независимым корпусом или статистическим доказательством общего улучшения. После просмотра результатов его следует считать regression-набором; следующий эксперимент требует нового отложенного набора.

| Набор | Требуемые фрагменты в поиске, до → после | В контексте модели, до → после |
|---|---:|---:|
| Development | 3/4 → 4/4 | 3/4 → 4/4 |
| Отложенные вопросы | 3/9 → 4/9 | 3/9 → 4/9 |

Регрессий нет. Development включает одну слабую проверку присутствия двух издателей; остальные проверки требуют источник, страницу и точную опорную цитату. Отложенное сравнение требует **оба** факта. Поэтому эти суммы нельзя трактовать как точность ответов или универсальный recall: альтернативные корректные источники также могут не совпасть с разметкой.

Пять случаев остаются неуспешными: источники прироста добычи вне OPEC+, прогноз добычи OPEC+ от EIA, корзина OPEC, спрос Китая и сопоставление роста спроса в 2026. В двух EIA-вопросах упоминание OPEC как объекта анализа дополнительно включает поиск по издателю OPEC. Контекст начала страницы помогает только когда нужная страница уже найдена и факт находится близко к её началу. Эти ограничения сохранены, а не исправлялись по открытым результатам holdout.

Воспроизведение из core/ после индексации:

```bash
python scripts/eval_reports.py --baseline
python scripts/eval_reports.py
python scripts/eval_reports.py --split holdout --baseline
python scripts/eval_reports.py --split holdout
```

Результат содержит SHA256 набора, snapshot индекса, метрики до/после ограничения контекста и provenance выбранных страниц. [Сохранённое сравнение](retrieval-context-evidence.json). Расход GigaChat на этот этап: **0 токенов**. Полный Ouroboros не запускался; evolution и synthetic self-improvement checks не менялись.
